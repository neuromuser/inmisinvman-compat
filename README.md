# Inmis + Inventory Management Compatibility

A lightweight Fabric mod that adds [Inventory Management](https://modrinth.com/mod/inventory-management) support to [Inmis](https://modrinth.com/mod/inmis) backpacks.

## What does this do?

This mod enables the **Sort**, **Transfer All**, and **Auto Stack** buttons from Inventory Management to work with Inmis backpacks!

## Features

✅ **Sort** your backpack inventory alphabetically  
✅ **Transfer All** items between backpack and player inventory  
✅ **Auto Stack** items to consolidate stacks  

✅ Works with all Inmis backpack tiers  
✅ Client-side only - works on servers without installation  

## Compatibility
- **Minecraft:** 1.20.1
- **Loader:** Fabric
- **Dependencies:** Fabric API, Inmis, Inventory Management

## How it works
This mod registers Inmis's `BackpackScreenHandler` with Inventory Management's button system, allowing the sorting/transfer/stacking functionality to recognize and work with Inmis backpacks.
